# PunjabTech
🚀 Client Management & Project Delivery Platform for Freelancers & Agencies

## 🌟 Features
• **Client Onboarding** - Structured intake forms with archetype classification (SaaS AI, Consumer Mobile, Marketplace, Enterprise)
• **Legal Document Management** - NDA & Master Services Agreement tracking with status workflow
• **Sprint & Milestone Tracking** - Phase-based project delivery with progress monitoring
• **Invoice & Payment Integration** - Stripe-powered milestone invoicing
• **Drag-and-Drop Workflow** - dnd-kit for intuitive task management
• **Responsive UI** - shadcn/ui components with framer-motion animations
• **Modern Stack** - Next.js 16, TypeScript, Drizzle ORM, TailwindCSS v4

## 🏕️ Use Cases
• Freelancers managing multiple client projects
• Agencies handling complex deliverables with milestone payments
• Tech consultants structuring client onboarding & legal workflows
• Startups needing scalable client management systems

## 📦 Quick Start

```bash
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) to start managing clients.

## 🔧 Tech Stack
• **Framework**: Next.js 16 (App Router)
• **ORM**: Drizzle ORM with PostgreSQL
• **UI**: shadcn/ui, lucide-react, framer-motion
• **Styling**: TailwindCSS v4
• **Auth**: better-auth, next-auth5 beta
• **Payments**: Stripe integration via milestone_invoices
